# img2 Interior — showcase media

Optimized preview images for the img2 Interior package README. This repository is intentionally public so package readers do not need access to the private plugin repository to load the previews.

## Walnut / Petrol — Bedroom Study

![AI-generated bedroom reference on the left and the authored Blender reconstruction on the right.](bedroom-comparison.webp)

**Left:** an AI-generated design reference, not a photograph or measured survey. **Right:** an actual render of the authored Blender scene after reopening the native deliverable. Neither side has been AI-retouched for this comparison; only resizing, preview compression and labels were added.

![Archived browser screenshot showing the reconstructed bedroom, source comparison, camera views, wireframe, curtain controls and download links.](bedroom-viewer.webp)

**Browser:** a static screenshot of the working Three.js project, not a hosted live demo. The visible controls belong to that project; the image itself is not interactive.

### Scope and limitations

- These are archived results from a project built with plugin **0.2.0**, including scene-specific geometry, materials and viewer integration. They are not a fresh benchmark of 0.3.0 or a guarantee for other reference images.
- Camera framing, room proportions, fabric folds, lighting and hidden geometry differ from the reference. This is an authored interpretation, not a pixel match.
- The viewer uses baked indirect lighting; curtain motion does not provide fully dynamic global illumination. The portable export is static and does not reproduce every native/runtime material behavior.
- Only these optimized, metadata-stripped previews and their captions are published here. No plugin implementation, full-resolution input, Blender/GLB file, texture library, credentials or private production reports are included.
